An honest-majority threshold ECDSA protocol over secp256k1 — no single party ever holds the key, any t of n sign, and every share is checked against public Feldman commitments so a cheater is named, not just rejected. Everything on this page is computed live in your browser: the protocol's own Rust code, compiled to WebAssembly.

1 · Shamir sharing + Feldman verification SPEC §4.1–4.2

A dealer samples a degree-(t−1) polynomial whose constant term is the secret; party j receives the evaluation p(j). Any t shares interpolate p(0); fewer learn nothing. The dealer also publishes A = (a₀·G, a₁·G, …) — the Feldman commitment — so every share can be checked: share·G == Σ jℓ·Aℓ. Deal below, verify every share, then reconstruct.

2 · The real 2-of-3 committee keygen SPEC §6

Not a mock — this card runs the protocol's commit-reveal Pedersen DKG (sim::run_keygen, the exact code path the test suite and the Sepolia demo drive) with your seed.
